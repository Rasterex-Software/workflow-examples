# Measurement & Takeoff

This is the standalone Measurement & Takeoff project inside the monorepo.

It uses the existing Measurement & Takeoff scenario and shared implementation from the repository root. No workflow UI or behavior is duplicated here.

## Run

From the repository root:

```bash
npm --prefix workflows/measurement-takeoff run dev
```

## Build

```bash
npm --prefix workflows/measurement-takeoff run build
```
